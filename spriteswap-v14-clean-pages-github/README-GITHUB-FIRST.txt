SpriteSwap V13 - GitHub root-ready
=================================

Upload the CONTENTS of this folder directly to the ROOT of your GitHub repository.

Correct repo layout:
  index.html
  styles.css
  theme-v13.css
  app.js
  config.js
  sprites-data.js
  vercel.json
  package.json
  api/
  assets/

Do NOT upload a single outer "spriteswap" folder into the repo.

Alternative: if your repo already has a spriteswap/ folder, keep it and set:
Vercel Project -> Settings -> Build and Deployment -> Root Directory = spriteswap
then redeploy.

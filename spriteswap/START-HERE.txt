SpriteSwap V20
==============
1. If you already ran the V19 schema.sql, do NOT run anything new in Supabase.
2. Unzip this package.
3. Replace the files at the ROOT of your GitHub SpriteSwap repo.
4. Commit/push to main.
5. Let the existing Vercel project redeploy automatically.
6. Hard-refresh the browser after deploy (Ctrl+Shift+R).

No new Vercel variables are required.
See V20-UPDATE.txt for the changes.

SpriteSwap V22 — Accepted Trade Chat

REQUIRED BEFORE TESTING:
1. Open Supabase -> SQL Editor.
2. Run the entire latest schema.sql once.
3. Push the V22 files to the root of the existing GitHub repo.
4. Let the same Vercel project redeploy.
5. Make sure Vercel Deployment Protection / Vercel Authentication is disabled for Production.

TEST WITH TWO DISCORD ACCOUNTS:
A. Account A posts a trade.
B. Account B opens it and requests the trade.
C. Account A sees the request, accepts it through the SpriteSwap safety modal.
D. The public listing leaves the open board.
E. Both accounts see the accepted trade in Messages.
F. Send a message in both directions.
G. Both accounts press Mark completed. The trade completes at 2/2.
H. Rating becomes available after completion.

V22 blocks new messages unless an accepted trade request exists for those two users + that trade.

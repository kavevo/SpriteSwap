SpriteSwap V18 — Profile + Sprite Detail Pass
==============================================

Main fixes
- Public profile Sprite cards are larger and show the entire Sprite artwork.
- Profile collection uses 5 columns on desktop, 4/3 responsively, 2 on phones.
- Profile collection now has search, variant, rarity, and mastered filters.
- Added Share Profile.
- Added a dedicated Sprite details page: /sprite?id=<sprite-id>
- Sprite detail pages show full artwork, variant, rarity, drop chance, season, source, ownership/mastery, and live trades.
- Home Sprite Vault cards link to Sprite details.
- My Collection cards link to Sprite details.
- Live trade offer/want artwork links to Sprite details.
- "I have this" / "I want this" from a Sprite page pre-fills the Post Trade page.
- Find live trades from a Sprite page opens the trade board with the Sprite name prefilled.
- Kept V16/V17 live Fortnite.GG catalog syncing and smart trade matching.

Setup
- No new Vercel environment variables.
- No new Supabase schema changes beyond the V16 live-catalog schema.
- Replace the files at the root of your existing GitHub SpriteSwap repo and push to main.

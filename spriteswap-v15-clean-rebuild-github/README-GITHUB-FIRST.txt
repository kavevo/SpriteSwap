SPRITESWAP — GITHUB DEPLOY
=========================

Your GitHub repo root should contain index.html directly:

SpriteSwap/
  index.html
  theme-v15.css
  styles.css
  app.js
  page-app.js
  v14-router.js
  profile.html
  messages.html
  collection.html
  notifications.html
  new-trade.html
  settings.html
  report.html
  admin.html
  api/
  assets/
  ...

Do not upload a parent folder so the repo becomes SpriteSwap/spriteswap/index.html.

Once committed to the main branch, the existing Vercel Git integration should deploy automatically and keep the same Vercel environment variables.

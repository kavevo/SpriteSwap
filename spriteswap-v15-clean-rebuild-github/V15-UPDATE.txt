SpriteSwap V15 — CLEAN REBUILD
==============================

Main fixes
- Rebuilt the hero layout so it cannot collapse into the broken giant-image layout from V14.
- Featured Sprite cards now have explicit size/position rules.
- Jump-to variant chips are properly styled and filter the Sprite Vault.
- Header search icon, input, shortcut badge and nav spacing are fixed.
- Removed legacy background/shine effects from the visible V15 theme.
- Cleaner charcoal / warm-slate / muted-purple visual system.
- Reworked Sprite cards, trade cards, collector cards, stats and controls.
- Better responsive behavior for desktop, tablet and mobile.

Pages
- Profile, Collection, Messages, Notifications, New Trade, Settings, Reports and Admin remain real pages.
- Profile Collection / Reviews tabs now work.
- Rating links now open the real profile page with a rating form.
- Messages All / Unread / Active / Closed filters now work.
- Messages trader search now works.
- Trade details in Messages include Sprite artwork when it can be matched.
- Header account dropdown is available on app pages.

Deployment
- This package is GitHub-root ready. Upload the CONTENTS of this folder to the root of the SpriteSwap GitHub repo.
- Do not put the files inside another spriteswap/ folder.
- No new Supabase SQL is required if V12+ schema is already running.
- No new Vercel environment variables are required.
